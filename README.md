机房面积利用率=机房占用总面积/机房使用面积，得到机房空间占用率情况，机房总面积包含以下几部分
## 设备占用面积
分专业计算 各专业设备数量转化按一个机架可装45U，每个设备高度U，计算每个专业设备占用多少个设备架数量，设备机柜 按 0.6*0.6*3=1.08平方米，
## 列头柜面积
按每列两个设备柜算：2.16平方米，具体行数可从机架位-所属机房-所在行去重计算得来
## ODF/IODF面积
0.3*0.6*3=0.54平方米
## 动力配套维护面积：
- 业务汇聚：6平方
- 普通汇聚：10平方
- 重要汇聚：20平方
## 空调：按每台1平方；
- 空调表格，统计每个汇聚机房的空调数量，计算出每个汇聚机房的空调占用面积
## 室内油机面积：
- 业务汇聚：10平方
- 普通汇聚：15平方
- 重要汇聚：40平方
## 外电占用面积：仅计算机房业务级别为重要汇聚时，才计算外电占用面积
重要汇聚：55平方

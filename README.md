<!-- - 必须运行环境 -->
python==3.8.10
<!-- - 使用前说明 -->
1. 安装python3.8.10
2. 安装依赖库
```
pip install -r require.txt
```
3. 创建必须包含的文件夹，用于存放数据库
```
mkdir data
```
<!-- - 数据库文件说明 -->
4. 数据库文件说明
```
data/
├── database.db
```
<!-- - 数据库来源 -->
5. 数据库来源
    1. 现网在用态的汇聚机房
    2. 汇聚机房机架位
    3. 汇聚机房内所有设备类型的高度
    4. 汇聚机房内所有专业设备清单

<!-- - 数据库来源 -->
# 4. 数据库来源
    1. 现网在用态的汇聚机房
    2. 汇聚机房机架位
    3. 汇聚机房内所有设备类型的高度
    4. 汇聚机房内所有专业设备清单
    5. 汇聚机房内所有专业空调清单

# 5. 使用需求修改需求
机房占用面积由以下几部分组成，除以机房使用面积，得到机房空间占用率情况
## 设备占用面积
分专业计算 各专业设备数量转化按一个机架可装42U，每个设备高度U，计算每个专业设备占用多少个设备架数量，设备机柜 按 0.6*0.6*3=1.08平方米，

## 列头柜面积
按每列两个设备柜算：2.16平方米，具体行数可从机架位-所属机房-所在行去重计算得来
## ODF/IODF面积
0.3*0.6*3=0.54平方米

## 动力配套（电源电池），考虑维护面积：
- 业务汇聚：6平方
- 普通汇聚：10平方
- 重要汇聚：20平方

## 空调（需动力室提供）：按每台1平方；
- 新增导入空调表格，统计每个汇聚机房的空调数量，计算出每个汇聚机房的空调占用面积
  
## 室内油机面积：（只有去年开展新建的普通汇聚机房有）
- 业务汇聚：10左右
- 普通汇聚：15左右
- 重要汇聚：40平方

## 外电占用面积：仅计算重要汇聚
重要汇聚：55平方
